Política de Privacidade

VI Estrelas BR · Última atualização: 25 de novembro de 2026

Esta política explica quais dados o app do VI Estrelas BR usa e como eles são tratados. Ele é um programa de uso pessoal do canal para publicar vídeos curtos nas contas do próprio canal.

1. Dados que usamos

  • Informações básicas da conta (nome de exibição, foto de perfil e identificador), para mostrar qual conta está conectada.
  • Token de acesso liberado pela rede social no login oficial, para enviar os vídeos.
  • Vídeos e legendas escolhidos por quem usa, que são enviados para publicação.

2. Onde os dados ficam

Tudo fica guardado apenas no computador de quem usa o programa. Não existe servidor nosso recebendo esses dados. A senha das redes sociais nunca é vista nem guardada.

3. Com quem compartilhamos

Os vídeos e as legendas são enviados apenas para a rede social escolhida (TikTok, YouTube, Instagram ou Facebook), pelas APIs oficiais. Não vendemos nem compartilhamos dados com terceiros.

4. Como apagar

Para apagar os dados, desconecte a conta no programa (Apps conectados → Desconectar). Você também pode revogar o acesso nas configurações de segurança de cada rede. No TikTok, o caminho é Configurações e privacidade → Segurança → Apps e serviços.

5. Menores de idade

O programa não é destinado a menores de 18 anos.

6. Mudanças

Esta política pode ser atualizada. A data no topo da página mostra a versão em vigor.

7. Contato

Fale com a gente pelo canal youtube.com/@VI_EstrelasBR.
